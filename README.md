## Setup Instructions

**Everything runs in the browser.** Each app is Rust compiled to WebAssembly; the containers only serve static files. Files open through the browser's file picker and save as downloads, and nothing is stored server side, so there are no volumes.

**Your work lives in the browser, not on the server.** Preferences, LightCraft's photo library (in the browser's origin-private file system) and EffectCraft's offline cache belong to the browser profile that opened the app, per origin. Clearing site data, switching browsers, or reaching the app under a different hostname means starting empty. Export what you want to keep; the exported files are the backup, as with any desktop app.

**HTTPS.** WebGPU and the clipboard need a secure context. Over plain HTTP the apps fall back to WebGL2; put them behind your reverse proxy for the full experience.

**Fonts.** The browser builds ship with only two fonts. PhotoCraft, WordCraft, GridCraft, DeckCraft and CADCraft also list the Japanese, Chinese and Arabic families from [craft-fonts](https://github.com/storytold/craft-fonts), which their images serve alongside the app; a family is downloaded the first time you pick it or open a document that uses it.
